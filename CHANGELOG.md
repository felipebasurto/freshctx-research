# Changelog

## 0.1.0 — Unreleased

- Added the FreshCtx engineering thesis and autoresearch soul.
- Added a dependency-free live-context core with revision recovery, anchored
  relocation, deterministic selection, and request projection.
- Added invariant tests, a synthetic baseline comparison, and repeated CtxBench
  timing/determinism runner.
- Added byte-length projection framing so the oracle remains exact when source
  code contains FreshCtx-like delimiters.
- Added required-paper and public-repository manifests with fetch/verify tools.
- Added the normative no-model CtxBench evaluation protocol.
- Added preview Pi and Hermes adapters plus a zero-model capture provider.

No state-of-the-art or public-repository performance claim is made in this
release.
